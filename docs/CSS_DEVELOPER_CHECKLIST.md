# چک‌لیست توسعه‌دهنده CSS (فارسی)

## اضافه کردن کامپوننت جدید
- [ ] فایل جدید در `src/public/css/2-components/` ایجاد شده و در `app.css` import شده است.
- [ ] کلاس پایه و Modifierها طبق الگوی `component`, `component--modifier`, `component__part` نام‌گذاری شده‌اند.
- [ ] متغیرهای رنگ/فاصله از `1-foundation/variables.css` مصرف می‌شوند (hardcode نشده‌اند).
- [ ] حالت‌ها (`:hover`, `:focus`, `.is-disabled`) مستند و تست شده‌اند.
- [ ] مثال دمو در یکی از صفحات `demo-*.html` اضافه یا به‌روزرسانی شده است.

## تست Theme Switching
- [ ] در `<html>` مقدار `data-theme="admin"` و `data-theme="user"` تست شده است.
- [ ] کنتراست رنگ‌ها در هر دو theme با WCAG حداقل سطح AA مطابقت دارد.
- [ ] متغیرهای theme برای رنگ و پس‌زمینه به‌درستی override شده‌اند.

## تست Responsive
- [ ] در عرض‌های <480px، 768px و >=1024px چک شده است.
- [ ] Grid و spacing در موبایل تداخل ندارد و عناصر قابل اسکرول هستند.
- [ ] ناوبری (top/drawer) در موبایل و دسکتاپ قابل استفاده است.

## تست RTL
- [ ] جهت‌دهی متن و آیکون‌ها در RTL صحیح است (هیچ وارونگی ناخواسته‌ای وجود ندارد).
- [ ] جداول و فرم‌ها در RTL بدون به‌هم‌ریختگی نمایش داده می‌شوند.
- [ ] عناصر pseudo (مثل caret، breadcrumb) در RTL در جای درست قرار گرفته‌اند.

## تست دسترس‌پذیری (Accessibility)
- [ ] فوکوس‌پذیری تمام کنترل‌ها بررسی و visible focus ring وجود دارد.
- [ ] نقش‌های ARIA و برچسب‌های فرم (label/for) هم‌خوان هستند.
- [ ] خوانایی متون (line-height، اندازه فونت) در themeهای مختلف مناسب است.
- [ ] اجتناب از استفاده غیرضروری از `!important` برای حفظ ترتیب طبیعی فوکوس و استایل.
