# Migration runbook — teams.org_node_id & user_team_assignment trigger

## Pre-checks (no changes)
1. Confirm current teams columns:
   ```bash
   psql "$DATABASE_URL" -c "SELECT column_name, data_type FROM information_schema.columns WHERE table_schema='public' AND table_name='teams' ORDER BY ordinal_position;"
   ```
2. Check for existing org_node_id FK/index:
   ```bash
   psql "$DATABASE_URL" -c "SELECT conname FROM pg_constraint WHERE conrelid='public.teams'::regclass AND conname='teams_org_node_id_fkey';"
   psql "$DATABASE_URL" -c "SELECT indexname FROM pg_indexes WHERE schemaname='public' AND tablename='teams' AND indexname='teams_org_node_id_idx';"
   ```
3. Review current trigger function source:
   ```bash
   psql "$DATABASE_URL" -c "SELECT pg_get_functiondef('public.trg_user_team_assignment_propagate_fn'::regproc);"
   ```

## Apply (idempotent)
Run inside a maintenance window with a backup/snapshot taken:
```bash
psql "$DATABASE_URL" -f docs/migrations/2025-12-19_add_teams_orgnode_and_fix_assignment.sql
```

## Post-checks
1. Verify column, FK and index now exist:
   ```bash
   psql "$DATABASE_URL" -c "SELECT column_name, data_type, is_nullable FROM information_schema.columns WHERE table_schema='public' AND table_name='teams' AND column_name='org_node_id';"
   psql "$DATABASE_URL" -c "SELECT conname, confdeltype FROM pg_constraint WHERE conrelid='public.teams'::regclass AND conname='teams_org_node_id_fkey';"
   psql "$DATABASE_URL" -c "SELECT indexname FROM pg_indexes WHERE schemaname='public' AND tablename='teams' AND indexname='teams_org_node_id_idx';"
   ```
2. Confirm trigger function only mirrors membership (no role branching):
   ```bash
   psql "$DATABASE_URL" -c "SELECT pg_get_functiondef('public.trg_user_team_assignment_propagate_fn'::regproc);"
   ```
3. Smoke-check propagation works (optional, on staging data):
   ```bash
   psql "$DATABASE_URL" -c "INSERT INTO public.user_team_assignment (user_id, team_id) VALUES ('<uuid>', <team_id>) ON CONFLICT (user_id) DO UPDATE SET team_id=EXCLUDED.team_id RETURNING *;"
   psql "$DATABASE_URL" -c "SELECT team_id, user_id, role, active FROM public.team_users WHERE user_id='<uuid>' ORDER BY created_at DESC LIMIT 5;"
   ```

## Rollback / contingency

  ```bash
  BEGIN;
  ALTER TABLE public.teams DROP CONSTRAINT IF EXISTS teams_org_node_id_fkey;
  ALTER TABLE public.teams DROP COLUMN IF EXISTS org_node_id;
  -- recreate previous trg_user_team_assignment_propagate_fn definition from backup if necessary
  COMMIT;
  ```
- Prefer restoring from the pre-migration snapshot instead of dropping data in production.
