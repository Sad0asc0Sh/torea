## Technology Stack

The project is **NOT** a React/Vite application. It is:
- **Backend:** Node.js + Express v5
- **Frontend:** EJS templates (server-side rendering)
- **Database:** PostgreSQL
- **Styling:** Mobile-first CSS (no React, no Vite)

For complete technology details, see [ARCHITECTURE_CURRENT.md - Technology Stack](../../ARCHITECTURE_CURRENT.md#technology-stack).
