## معرفی

مدیریت کاتالوگ یک ابزار پیشرفته برای مدیریت منوی ناوبری سیستم است که:

- ✅ **خودکار**: صفحات را از کد شما کشف می‌کند
- ✅ **بصری**: با نمای درختی، لیستی و کانبان
- ✅ **قدرتمند**: با فیلترها و جستجوی پیشرفته
- ✅ **فارسی**: کاملاً به زبان فارسی
- ✅ **دسترسی‌پذیر**: با پشتیبانی کامل کیبورد

## شروع سریع

### گام 1: دسترسی

به آدرس زیر بروید:
```
/admin/settings/catalog-manager
```

### گام 2: مشاهده آمار

در بالای صفحه آمار کاتالوگ را ببینید:
- **کل آیتم‌ها**: تعداد کل صفحات کشف شده
- **جدید**: صفحاتی که در دیتابیس نیستند
- **فعال**: صفحات فعلاً نمایش داده می‌شوند
- **مخفی**: صفحات غیرفعال

### گام 3: انتخاب آیتم‌ها

چکباکس‌ها را برای انتخاب صفحاتی که می‌خواهید در منو نمایش دهید، تیک بزنید.

یا از دکمه‌های سریع استفاده کنید:
- **☑ انتخاب همه**: همه آیتم‌ها
- **☐ لغو**: لغو همه انتخاب‌ها
- **✨ جدیدها**: فقط صفحات جدید
- **✓ فعالها**: فقط صفحات فعلی

### گام 4: ویرایش عناوین

در ستون "عنوان فارسی" روی هر فیلد کلیک کنید و عنوان مناسب را تایپ کنید.

یا روی دکمه ✏️ کلیک کنید تا پنل جزئیات باز شود.

### گام 5: ذخیره

روی **💾 اعمال تغییرات** کلیک کنید.

## رابط کاربری

### آمار (Stats Cards)

```
┌─────────┬─────────┬─────────┬─────────┐
│ کل: 45  │ جدید: 8 │ فعال: 32│ مخفی: 5 │
└─────────┴─────────┴─────────┴─────────┘
```

### فیلترها (سمت چپ)

**🔍 جستجو**: جستجو در عنوان یا کلید

**وضعیت**:
- 🆕 جدید
- ✅ فعال
- ⭕ مخفی

**منبع**:
- 🛤️ Route (از فایل‌های route)
- 📄 EJS (از فایل‌های view)
- 💾 Database (از دیتابیس)

**نوع**:
- صفحه
- گروه
- تنظیمات

### نماها (Views)

**🌳 درختی**: نمای سلسله‌مراتبی با indent
- مناسب برای دیدن ساختار کلی
- امکان باز/بسته کردن شاخه‌ها

**📋 لیستی**: نمای جدول ساده
- مناسب برای ویرایش سریع
- نمایش فشرده

**📊 کانبان**: نمای کارت‌ها در ستون‌ها
- مناسب برای مدیریت وضعیت‌ها
- بصری و جذاب

## ویژگی‌ها

### 1. کشف خودکار

سیستم به طور خودکار:
- فایل‌های route در `src/routes/admin/**/*.js` را اسکن می‌کند
- فایل‌های view در `src/views/admin/**/*.ejs` را می‌خواند
- صفحات جدید را شناسایی می‌کند

### 2. ویرایش آنلاین

**ویرایش سریع** (Inline):
- مستقیم در جدول روی فیلد کلیک کنید
- تایپ کنید
- تغییر خودکار ذخیره می‌شود (در حافظه)

**ویرایش کامل** (Properties Panel):
- روی ✏️ کلیک کنید
- تمام فیلدها قابل ویرایش هستند:
  - عنوان فارسی
  - توضیحات
  - آیکون (emoji)
  - نوع
  - والد
  - ترتیب

### 3. فیلترهای پیشرفته

**جستجو**:
- جستجو در عنوان و کلید
- تایپ کنید و نتایج لحظه‌ای ببینید

**فیلتر ترکیبی**:
- چند فیلتر را با هم استفاده کنید
- مثلاً: صفحات جدید از نوع گروه

### 4. حالت تاریک

روی 🌙 کلیک کنید تا به حالت تاریک (Dark Mode) تغییر کند.

تنظیمات ذخیره می‌شود و دفعه بعد همان حالت لود می‌شود.

### 5. عملیات دسته‌ای (Bulk Actions)

- انتخاب همه
- لغو انتخاب همه
- انتخاب گروهی (جدیدها، فعال‌ها)
- باز/بسته کردن همه شاخه‌ها

---

## میانبرهای کیبورد

| کلید | عملکرد |
|------|--------|
| `Ctrl + A` | انتخاب همه |
| `Ctrl + D` | لغو انتخاب همه |
| `Ctrl + S` | ذخیره تغییرات |
| `Ctrl + F` | فوکوس روی جستجو |
| `Esc` | بستن پنل‌ها |
| `?` | نمایش راهنمای میانبرها |

برای مشاهده لیست کامل روی ⌨️ کلیک کنید.

## نکات و ترفندها

### نکته 1: سازماندهی بهتر

از نوع "گروه" برای دسته‌بندی صفحات استفاده کنید:

```
📁 مدیریت (group)
├─ 📄 کاربران (page)
├─ 📄 نقش‌ها (page)
└─ 📄 دسترسی‌ها (page)
```

### نکته 2: استفاده از Emoji

از emoji برای آیکون‌ها استفاده کنید:

- 🏠 داشبورد
- ⚙️ تنظیمات
- 📊 گزارش‌ات
- 👥 کاربران
- 🛒 فروش

### نکته 3: ترتیب منطقی

از فیلد "ترتیب" برای مرتب‌سازی استفاده کنید:

- 0: اولین آیتم
- 10: دومین آیتم
- 20: سومین آیتم

فاصله بگذارید تا بعداً راحت‌تر بتوانید آیتم جدید اضافه کنید.

### نکته 4: پاک کردن کش

اگر تغییراتی در کد زدید و صفحات جدید نمایش داده نمی‌شوند:

1. روی 🔄 کلیک کنید
2. صبر کنید تا کشف مجدد انجام شود

### نکته 5: استفاده از نماهای مختلف

- **درختی**: برای دیدن ساختار کلی
- **لیستی**: برای ویرایش سریع تعداد زیاد
- **کانبان**: برای مدیریت وضعیت‌ها

## عیب‌یابی

### مشکل: صفحه جدید نمایش داده نمی‌شود

**علت**: کش 5 دقیقه‌ای فعال است

**راهحل**:
1. روی 🔄 (پاک کردن کش) کلیک کنید
2. یا 5 دقیقه صبر کنید

### مشکل: تغییرات ذخیره نمی‌شوند

**علت**: فرم submit نشده

**راهحل**:
- مطمئن شوید روی "💾 اعمال تغییرات" کلیک کرده‌اید
- چک کنید حداقل یک آیتم انتخاب شده باشد

### مشکل: عناوین فارسی به هم می‌ریزند

**علت**: مشکل encoding

**راهحل**:
- مطمئن شوید database با encoding UTF-8 است
- فایل‌های `.ejs` باید UTF-8 باشند

### مشکل: صفحه خیلی کند است

**علت**: تعداد زیاد آیتم‌ها (500+)

**راهحل**:
- از فیلترها استفاده کنید
- از نمای لیستی استفاده کنید (سبک‌تر از درختی)
- کش کردن را فعال کنید

## سوالات متداول

**س: آیا می‌توانم صفحات دستی اضافه کنم؟**

پ: بله، از پنل Properties روی "افزودن دستی" کلیک کنید (در نسخه‌های آینده).

**س: آیا تغییرات بلافاصله در منو اعمال می‌شوند؟**

پ: بله، بعد از ذخیره بلافاصله در منوی کاربری نمایش داده می‌شوند.

**س: آیا می‌توانم چند نفر همزمان ویرایش کنند؟**

پ: خیر، فعلاً پشتیبانی نمی‌شود. آخرین ذخیره اعمال می‌شود.

**س: آیا می‌توانم صفحات را جابجا کنم (drag & drop)؟**

پ: فعلاً خیر، ولی در نسخه‌های بعدی اضافه می‌شود.
