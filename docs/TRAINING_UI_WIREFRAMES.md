## 📑 فهرست صفحات

### Admin Pages:
1. Admin Training Record - ضبط تمرین
2. Admin Negotiation Analysis - تحلیل مذاکره
3. Admin Training Settings - تنظیمات
4. Admin Topics Management - مدیریت موضوعات
5. Admin Team Report - گزارش تیم

### User Pages:
6. User Dashboard - داشبورد کاربر
7. User Customer Search - جستجوی مشتری
8. User Customer History - تاریخچه مشتری
9. User Progress - پیشرفت من
10. User Leaderboard - رتبهبندی

### Mobile:
11. GPS Proximity Alert
12. Bottom Sheet
